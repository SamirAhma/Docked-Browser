Help & about

Each name is its own Chrome — cookies, dock icon, and window stay separate.

Open
Starts that browser. A new name creates a fresh profile.
Pause
Sleeps it in RAM (almost no CPU). Unused profiles auto-sleep via predict-sleep (ambient LinUCB). Resume opens that exact profile.
Close
Quits the window. Bookmarks stay for next time.
Delete
Erases that saved browser for good (cookies, bookmarks, icon). Use below when Advanced is on.
Icon
Click the picture to set a dock icon. Hover and tap × to reset.
Advanced
Toggle in the header for pause/resume/close all, maintenance tools, and the activity log. CPU and RAM stay on each open browser.

Strengths

  • One window per context
  • Custom dock icons
  • Pause without quitting
  • Leaves host Chrome alone

Good for

  • Work vs personal
  • Parking heavy sessions
  • Opening only what you need

Limits

  • Not a VPN or VM
  • Needs Docker + Linux
  • Pause keeps RAM

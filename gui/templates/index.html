Docked Browser

One Chrome per name. Pause what you’re not using.

Install Chrome once to get started.

Help & about

Each name is its own Chrome — cookies, dock icon, and window stay separate.

Open
Starts that browser. A new name creates a fresh profile.
Pause
Sleeps it in RAM (almost no CPU). Resume wakes it. Pause does not free memory.
Close
Quits the window. Bookmarks stay for next time.
Icon
Click the picture to set a dock icon. Hover and tap × to reset.

Strengths

  • One window per context
  • Custom dock icons
  • Pause without quitting
  • Leaves host Chrome alone

Good for

  • Work vs personal
  • Parking heavy sessions
  • Opening only what you need

Limits

  • Not a VPN or VM
  • Needs Docker + Linux
  • Pause keeps RAM

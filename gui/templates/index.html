Docked Browser

Chrome profiles with clearer cues — so you can focus on one job at a time. Other people use it for clients, shopping, or experiments; you choose the names.

What this is

Advantages

  • One named window per context — easier to stay focused
  • Custom dock icons so you pick the right Chrome
  • Pause a window without quitting
  • Doesn’t touch your normal host Chrome

Use cases

  • Focus: only open the window you need right now
  • Work / personal / shopping kept apart
  • Park a heavy session and come back later
  • Whatever split helps your brain — names are yours

Weaknesses

  • It’s profile separation — not a VPN or VM
  • Needs Docker + a Linux desktop
  • Pause keeps RAM; doesn’t free memory
  • Still shares your IP, machine, and Downloads

What do these buttons mean?

Think of each name as a separate Chrome app on your computer.

Open Chrome
Starts a browser for that name. If the name is new, a fresh profile is created automatically (new dock icon too).
Pause (freeze)
Keeps the window’s memory, but uses almost no CPU — like putting it to sleep. Use Resume (or the dock right‑click menu) to wake it. The dock icon itself stays the same — GNOME does not let us dim it reliably.
Resume
Wakes a paused browser back up.
Close Chrome
Fully quits that browser. Your bookmarks/logins for that name are kept for next time.
Choose icon
Pick a custom image for this browser’s dock/taskbar icon. Remove icon restores the letter badge.
Install / Update install
Downloads Google Chrome into Docker. Do this once at the start, or later to update.
